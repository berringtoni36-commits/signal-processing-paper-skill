# Seed Literature Map

Use this list to start a verified literature review. The notes state why each paper may be relevant; they do not imply that the full text has been reviewed. Verify metadata at the DOI landing page and obtain a legal full-text copy before extracting technical details.

## Nonlinear ANC overview

- Lu et al., "Active noise control techniques for nonlinear systems," *Signal Processing*. DOI: https://doi.org/10.1016/j.sigpro.2020.107929  
  Use for problem taxonomy, historical positioning, and the role of nonlinear models. An author version is available as arXiv:2110.09672.

## Random features and kernel approximation

- "Multikernel adaptive filtering based on random features approximation," *Signal Processing*. DOI: https://doi.org/10.1016/j.sigpro.2020.107712  
  Use to position fixed-dimensional random-feature adaptive filtering and multikernel design.

## MCC and robust adaptive filtering

- "Euclidean direction search algorithm with maximum correntropy criterion for active noise control system," *Signal Processing*. DOI: https://doi.org/10.1016/j.sigpro.2024.109759  
  Use for recent MCC-based ANC positioning and comparison design.

- "Generalized kernel maximum correntropy criterion with variable center," *Signal Processing*. DOI: https://doi.org/10.1016/j.sigpro.2023.109294  
  Use for correntropy variants and kernel-parameter discussion.

- "Robust variable kernel width for maximum correntropy criterion," *Signal Processing*. DOI: https://doi.org/10.1016/j.sigpro.2020.107948  
  Use when motivating or testing kernel-width sensitivity.

- "Robust and sparsity-aware adaptive filters: A review," *Signal Processing*. DOI: https://doi.org/10.1016/j.sigpro.2021.108276  
  Use for broader robust-adaptive-filter context and evaluation language.

## Low-rank nonlinear adaptive filtering

- "Nonlinear spline adaptive filters based on a low rank approximation," *Signal Processing*. DOI: https://doi.org/10.1016/j.sigpro.2022.108726  
  Use to compare structured low-rank nonlinear adaptive models.

- "Fast and efficient acoustic feedback cancellation based on low rank approximation," *Signal Processing*. DOI: https://doi.org/10.1016/j.sigpro.2021.107984  
  Use for low-rank acoustic-processing motivation and complexity reporting.

- "Nonlinear acoustic echo cancellation using low complexity low rank RLS," *Signal Processing*. DOI: https://doi.org/10.1016/j.sigpro.2024.109623  
  Use for recent low-rank nonlinear acoustic adaptive-filter comparisons.

## Impulsive-noise ANC and related robustness

- "Projection FxLMS framework of active noise control against impulsive noise environments," *Signal Processing*. DOI: https://doi.org/10.1016/j.sigpro.2024.109624  
  Use for impulsive-noise baselines, test conditions, and robustness metrics.

- "Fractional-order generalized complex correntropy algorithm for robust active noise control," *Signal Processing*. DOI: https://doi.org/10.1016/j.sigpro.2025.110024  
  Use for recent correntropy-based robust ANC; verify whether the assumptions and data are comparable.
